# ecommercetask

A Flutter e-commerce application built with Clean Architecture and Cubit.

## Instructions for Running the Application

### 1. Install Dependencies
```bash
flutter pub get
```

### 2. Run the Application
```bash
flutter run
```

### 3. Run Tests
```bash
flutter test
```
