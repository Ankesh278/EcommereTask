# AuraWear Fashion - E-Commerce App

A simple Flutter e-commerce application built with Clean Architecture and Cubit state management.

## 📱 Features
- **Login Screen**: Form validation, password visibility toggle, demo credentials with auto-fill.
- **Product Listing Screen**: Static clothing products with price, rating, descriptions, product details sheet, and Add to Cart.
- **Cart Screen**: Dynamic quantity controls, auto-removal at zero quantity, direct delete, and total amount calculation.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd ecommercetask
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

4. **Run tests:**
   ```bash
   flutter test
   ```
