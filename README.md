# E-Commerce Product Listing App

A Flutter e-commerce application that fetches products from the [DummyJSON Products API](https://dummyjson.com/products) with search, product details, cart management, and error handling.

---

## Prerequisites

Before running the application, make sure you have the following installed on your machine:

- **Flutter SDK**: `>=3.10.0` ([Install Flutter](https://docs.flutter.dev/get-started/install))
- **Dart SDK**: Included with Flutter
- An Android Emulator, iOS Simulator, or a connected physical device (or Chrome for web)

Verify your setup:
```bash
flutter doctor
```

---

## How to Install

1. **Clone the repository** (or navigate to the project directory):
   ```bash
   cd ecommercetask
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

---

## How to Run

1. **Start the application**:
   ```bash
   flutter run
   ```

2. **Run on a specific device / platform**:
   - For Android:
     ```bash
     flutter run -d android
     ```
   - For iOS Simulator:
     ```bash
     flutter run -d ios
     ```
   - For Chrome (Web):
     ```bash
     flutter run -d chrome
     ```
   - For macOS:
     ```bash
     flutter run -d macos
     ```
